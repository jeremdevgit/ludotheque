# Sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public pour une faille de sécurité.
Utilise le signalement privé de GitHub : onglet **Security** du dépôt → **Report a vulnerability**.
Décris le problème, la version concernée, les étapes pour le reproduire et, si possible, une piste de correction.
Tu recevras une réponse dès que possible ; la correction sera publiée dans une nouvelle version, avec ton accord pour être cité.

## Versions suivies

Seule la dernière version publiée (page *Releases*) reçoit des correctifs.

## Ce que garantit le logiciel

- Aucune donnée personnelle incluse ; bibliothèque et réglages sur le Mac de l'utilisateur, identifiants dans le Trousseau macOS.
- Aucun service tiers contacté en dehors des plateformes connectées et des services publics de métadonnées listés dans le README.

## Hors périmètre

- Les intégrations GOG, Epic, PlayStation, Nintendo et Humble utilisent des API non officielles, qui peuvent changer sans préavis.
- L'application n'est pas notarisée par Apple (avertissement Gatekeeper) : vérifie l'empreinte SHA-256 publiée avec chaque version.
