# Security

**English** · [Français](#sécurité)

## Reporting a vulnerability

Please **do not** open a public issue for a security flaw.
Use GitHub's private reporting: the repository's **Security** tab → **Report a vulnerability**.
Describe the problem, the version affected, the steps to reproduce it and, if possible, a suggested fix.
You will get an answer as soon as possible; the fix will ship in a new release, crediting you if you agree.

## Supported versions

Only the latest release (*Releases* page) receives fixes.

## What the software guarantees

- No personal data included; library and settings stay on the user's Mac, credentials in the macOS Keychain.
- No third-party service contacted other than the connected platforms and the public metadata services listed in the README.

## Out of scope

- The GOG, Epic, PlayStation, Nintendo and Humble integrations use unofficial APIs, which can change without notice.
- The app isn't notarized by Apple (Gatekeeper warning): check the SHA-256 hash published with each release.

# Sécurité

[English](#security) · **Français**

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir de ticket public pour une faille de sécurité.
Utilise le signalement privé de GitHub : onglet **Security** du dépôt → **Report a vulnerability**.
Décris le problème, la version concernée, les étapes pour le reproduire et, si possible, une piste de correction.
Tu recevras une réponse dès que possible ; la correction sera publiée dans une nouvelle version, avec ton accord pour être cité.

## Versions suivies

Seule la dernière version publiée (page *Releases*) reçoit des correctifs.

## Ce que garantit le logiciel

- Aucune donnée personnelle incluse ; bibliothèque et réglages sur le Mac de l'utilisateur, identifiants dans le Trousseau macOS.
- Aucun service tiers contacté en dehors des plateformes connectées et des services publics de métadonnées listés dans le README.

## Hors périmètre

- Les intégrations GOG, Epic, PlayStation, Nintendo et Humble utilisent des API non officielles, qui peuvent changer sans préavis.
- L'application n'est pas notarisée par Apple (avertissement Gatekeeper) : vérifie l'empreinte SHA-256 publiée avec chaque version.
